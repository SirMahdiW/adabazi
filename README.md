# ادابازی 🎭 — بازی گروهی پانتومیم (نسخه وب)

بازی گروهی **پانتومیم و حدس کلمه** برای دورهمی‌ها — ساخته‌شده با HTML/CSS/JS خالص، **بدون هیچ فریمورکی**.

> **کاملاً رایگان:** بدون تبلیغات · بدون خرید درون‌برنامه‌ای · بدون حساب کاربری · بدون سرور · بدون جمع‌آوری داده

## ✨ امکانات

| | |
|---|---|
| 🎭 **سه حالت بازی** | ادبیات (پانتومیم)، بوم (چالش سریع)، ترانه (آوازی) |
| 📚 **۱۶,۳۰۵ کلمه ادبیات** | در ۱۸ دسته موضوعی + ۱,۰۲۹ چالش بوم + ۵۰ ترانه |
| 👥 **۲ تا ۶ تیم** | نام و رنگ دلخواه، امتیاززنی خودکار |
| ⚙️ **قوانین قابل تنظیم** | تعداد دور، زمان هر نوبت، کلمه در هر نوبت |
| ⏱️ **تایمر حلقه‌ای** | هشدار ۱۰ ثانیه آخر + صدا و لرزش |
| ↩️ **لغو آخرین کلمه** | بازگشت یک‌قدمی امتیاز |
| 📊 **تاریخچه و آمار** | ذخیره محلی روی دستگاه (localStorage) |
| 📴 **کار آفلاین** | PWA با سرویس‌ورکر — بعد از اولین بازدید بدون اینترنت هم کار می‌کند |
| 🎨 **طراحی Claymorphism** | گردی زیاد، مرز ۳px، سایه دوگانه بیرونی+داخلی، فشردن نرم ۲۰۰ms روی تم مشکی با رنگ‌های زنده |

## 🕹️ روش بازی

1. حالت بازی را انتخاب کن (ادبیات / بوم / ترانه)
2. تیم‌ها، دورها و زمان را تنظیم کن → **شروع بازی**
3. یک نفر کلمه را ادا کند، بقیه حدس بزنند
4. **درست** ← امتیاز کلمه برای تیم · **غلط / رد** ← بدون امتیاز
5. بعد از پایان زمان یا همه کلمه‌ها، نوبت تیم بعدی
6. بعد از هر دور خلاصه، و در پایان آخرین دور، **برنده** مشخص می‌شود

**میان‌برهای صفحه بازی:** `1` یا `→` درست · `2` یا `←` غلط · `Space` رد · `Z` بازگشت · `P` مکث

## 🚀 اجرا

فایل‌های استاتیک هستند؛ کافی است یک سرور محلی داشته باشید:

```bash
# پایتون
python -m http.server 8080

# یا Node
npx serve .
```

سپس `http://localhost:8080` را باز کنید.

> ⚠️ مستقیم با `file://` باز نکنید — مرورگر اجازه بارگذاری `data/words.json` را نمی‌دهد.

## 📁 ساختار پروژه

```
├── index.html          # پوسته SPA
├── manifest.json       # PWA manifest
├── sw.js               # سرویس‌ورکر (کش آفلاین)
├── css/
│   ├── tokens.css      # توکن‌های طراحی (رنگ، گردی، سایه clay، حرکت)
│   └── app.css         # همه کامپوننت‌ها
├── js/
│   ├── icons.js        # مجموعه آیکون SVG (stroke 2px)
│   ├── store.js        # ذخیره محلی تنظیمات/تاریخچه/آمار
│   ├── audio.js        # صداهای بازی با WebAudio (بدون فایل صوتی)
│   ├── data.js         # بارگذاری تنبل data/words.json
│   ├── confetti.js     # کانفتی مربعی روی canvas
│   ├── game.js         # موتور بازی (منطق خالص، بدون DOM)
│   └── app.js          # روتر و رندر صفحات
├── data/words.json     # ۵۰۶KB دیتای بازی (۱۶,۳۰۵+۱,۰۲۹+۵۰ محتوا)
├── icons/              # آیکون SVG و PNG (192/512)
└── analysis/           # گزارش مهندسی معکوس + CSVهای خام (مخصوص توسعه)
```

## 🎨 سیستم طراحی

- **Claymorphism:** شعاع گردی ۲۶–۴۰px، مرز ۳px، سایه دوگانه (`box-shadow` بیرونی تیره + `inset` روشن)، فشردن `translateY(4px)` در ۲۰۰ms با انیمیشن فنری
- **Vibrant:** پالت `#7C3AED` بنفش · `#F43F5E` قرمز · `#22D3EE` فیروزه‌ای · `#FBBF24` زرد · `#34D399` سبز
- **Block-based:** گرید بنتوی ۶ ستونه با بلوک‌های `span-2/3/4`
- **تم مشکی:** پس‌زمینه `#05050A` با سه درخشش شعاعی رنگی و شبکه ظریف
- **تایپوگرافی:** `Lalezar` (عنوان) + `Vazirmatn` (متن) از Google Fonts
- **دسترس‌پذیری:** `dir="rtl"`، لینک پرش، `focus-visible`، `prefers-reduced-motion`، کنتراست متن ≥ 4.5:1
