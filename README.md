# ادابازی — نسخه وب

بازی گروهی پانتومیم و حدس کلمه. رابط کاربری موبایل‌محور، تم روشن مینیمال و **بدون تبلیغات و بدون پرداخت درون‌برنامه‌ای**.

🌐 **اجرا:** https://sirmahdiw.github.io/adabazi/

---

## حالت‌های بازی
| حالت | توضیح |
|---|---|
| **ادابازی** | هر نوبت یک کلمه: تیم نوبت‌دار دسته را انتخاب می‌کند، امتیاز کلمه را مشخص می‌کند و بقیه حدس می‌زنند |
| **بوم** | کلمه به کلمه و دست‌به‌دست؛ هر بازیکن باید **سه** مورد بگوید |

## چه چیزی در این ریپو هست
```
index.html        پوسته‌ی اپ (تک‌صفحه‌ای، بدون فریم‌ورک)
manifest.json     تنظیمات PWA
sw.js             کش آفلاین (Service Worker)
css/tokens.css    توکن‌های طراحی (رنگ، فاصله، فونت، حرکت)
css/app.css       کامپوننت‌ها و صفحه‌بندی
js/game.js        موتور بازی — منطق نوبت‌ها، امتیاز، زمان‌ها و پایان بازی
js/app.js         روتر و صفحه‌ها (خانه، ساخت، گروه، دسته، بازی، بوم، رتبه‌بندی، …)
js/data.js        بارگذاری و نرمال‌سازی داده‌ی بازی
js/store.js       وضعیت محلی (localStorage)، آمار و تاریخچه
js/icons.js       آیکون‌های SVG
js/audio.js       صداهای بازی      |   js/confetti.js  کانفتی
data/words.json   ۱۶۳۰۵ کلمه + ۱۰۲۹ عبارت بوم + ۵۰ ترانه
fonts/            Vazirmatn + IBM Plex Sans Arabic + Lalezar (محلی، آفلاین)
icons/            آیکون اپ (PNG در چند سایز)
```

> سند کامل طراحی رابط کاربری در ریپوی پروژه‌ی اندروید
> (`SirMahdiW/pantoparty` → `UI-NOTE.md`) نگهداری می‌شود تا این ریپو فقط شامل خودِ سایت باشد.

## ساخت اندروید
پروژه‌ی اندروید در ریپوی جداگانه است: **[SirMahdiW/pantoparty](https://github.com/SirMahdiW/pantoparty)** — خروجی APK از طریق GitHub Actions ساخته می‌شود.

## توسعه
```bash
python -m http.server 8765      # اجرای محلی
# سپس: http://localhost:8765
```
بدون build step و بدون وابستگی — فایل‌ها همان‌طور که هستند اجرا می‌شوند.
